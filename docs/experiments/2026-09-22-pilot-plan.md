## 原有流量保护

- 以已发布版本 `76d95d97541ceb363e0568ce105f9360c7d2cdf1` 的干净导出构建为基准，记录全部58个原有文件的SHA-256。
- 保护基线仍为 `76d95d9`，不因新增入口和索引调整重置。除首页和sitemap外，其余56个原产物的SHA-256直接一致，包括原34篇文章、信息页、原JS/CSS/PDF、搜索索引、重定向与robots等。
- 首页FAQ结束后、页脚前使用普通内容区 `Free get-well resources`，仅链接 `Printable get-well cards for teachers` 和 `Practice get-well replies at work`。首页独立加载 `assets/experiments/home-resources-v1.css`；该样式不加入其他原页面。原导航、Finder、分类、其他正文和FAQ顺序均不变。
- 检查器要求首页恰好出现一个由 `Home resource entry: start/end` 标记的入口，核对位置和两个目标链接；同时严格核对 `Home resource styles: start/end` 内唯一获准的版本化CSS link。仅剥离这两个块后，首页须与原基线逐字节一致。
- 教师资源页与职场专题页明确使用 `index,follow`，sitemap各追加一次，总计41项；检查器仅剥离这两项后，原39项及其余文件字节必须与基线一致。5个练习与 `/resources/` 纯导航hub继续 `noindex,follow`，逐页理由已记录，不用字数门槛判断。8个新页面均不加入原站内搜索索引。
- 新页面主标题明确get-well主题，主导航统一为Finder / Situations / Guidance / FAQ，与原站一致；无重定向、无旧URL替换。
- 新PDF沿用原有 `/assets/printables/*.pdf` 的 `X-Robots-Tag: noindex` 规则。预览服务器不实现Cloudflare头部，部署后才可验证真实响应头。

- 一致性检查仅证明获准首页与sitemap增量之外的既有产物保持原样，不能保证未来自然流量不受搜索环境等外因波动。

## 内容审核与真人试用

新增5课程、1份独立职场回复指南、1份共享页面文案、2份PDF分别录入待人工审核，共9项；加原37项，总计46项均待人工审核。指南源文件为 `content/workplace-guide.js`，单独计算版本指纹。技术测试、AI交叉审查、视觉检查及索引授权均不记作真人编辑批准。

建议先各邀请5位符合条件的人，作为发现使用障碍的小样本：经常组织班级活动的家长或教师，以及工作中使用英语的非母语者。尚未联系或招募任何人；不得把模拟使用写成真实反馈。

组织者任务：按自己的班级人数选择纸张和页数，修改邀请模板，准备实际可交付的卡片。观察能否独立完成、哪一步仍需解释、签名空间是否够用；至少完成一次实际打印。询问他们原本会如何解决同样问题，而不只问“喜欢吗”。

学习者任务：选一项与自己的近期经历相近的情境，先作答，再看解释和例句。询问为什么选择、解释是否改变判断、最终还需修改哪里，以及下次会用这个练习还是直接查例句。真人英文编辑另行审核自然度、文化语境、隐私和未经确认的承诺。

观察记录模板：参与者匿名编号、任务背景、是否独立完成、卡住的位置、实际采用或修改的内容、原本替代方案、原话反馈（获准后记）、下一次修改。无需记录收信人的病情或身份。

不设未经数据支持的“行业转化率”。如果无人实际采用、仅称赞页面，则继续访谈或停止扩展；如果重复出现同一障碍，先修复再试。5人样本用于找问题，不能估算市场规模。

## 测量口径

| 事件 | 实际含义 | 不能推断 |
| --- | --- | --- |
| `resource_download_click` | 点击A4或Letter链接 | 已下载完成、已打印、已送出 |
| `resource_copy` | 复制API或回退复制成功 | 已发送、对方满意 |
| `practice_answer` | 检查一个选项，包含选项编号和正误 | 用户此前英语水平、学习效果 |
| `practice_complete` | 本次页面访问第一次查看答案反馈，无论对错 | 五题全部完成、掌握了知识 |

所有自定义事件仅在生产域名、允许的试验路径发送，并带 `experiment_id: resources_v1`。不发送正文、姓名、URL参数或片段；GA4自动元数据仍遵循既有隐私政策。页面明确解释统计类别和没有可恢复进度。当前本地预览不产生生产分析数据，GA4接收端尚未验证。

原流量应使用新导出的GSC数据按原URL及查询观察。2026-10-04已通过GSC现有浏览器登录取得9/2—9/29及8/5—9/1的28天对照，详见本地运营记录 `../网站运营数据/2026-10-04-GSC复核与下一步.md`；这不是新资源上线基线，新资源仍未发布。进入线上阶段前需按实际部署日刷新基线；访问量较少时单日涨跌不能归因于试验。

## 后续进入线上时的顺序

1. 真人文案审核和小样本试用仍待完成；按实际问题修订，不把技术通过写成人工批准。本轮不设置付费、账号或邮件收集。
2. 经另行发布后，通过直接链接及首页入口访问；两个正式资源页允许索引，其余6页维持noindex。运行已扩展的 `npm run validate:live`，检查实际下载响应、手机操作及GA4接收端。当前仍未发布生产，未运行本版线上验收，也不能声称Google已收录。
3. 有采用迹象后，再单独评估是否在教师页增加一个上下文入口。对原页面新增入口的授权目前只覆盖首页两个链接；教师页入口仍属于额外变更，需要独立检查差异，不能直接重置保护基线。
4. 两个资源页的索引范围已经用户同意并完成本地配置。5个单题和导航hub日后是否开放索引，依据独立任务与实际反馈重新评估；不要为索引凑字数、一次给所有旧页面增加入口或批量扩写。

当前版本撤回方式：先移除 `generate-pages.js` 中 `Home resource entry: start/end` 包围的资源 `section` 及标记，同时移除 `Home resource styles: start/end` 内的CSS link及标记；再撤回新增试验文件和 `package.json` 中对应的构建、检查hook。退出试验构建hook后重新构建，由原生成器恢复39项sitemap，两项资源增量随之移除。保护检查同时恢复为全部58个原产物直接比对同一份 `76d95d9` 基线，不重置基线。若以后已对外分享新URL，需根据链接使用情况单独决定保留说明页还是移除，避免盲目批量重定向。
