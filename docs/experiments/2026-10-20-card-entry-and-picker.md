# 2026-10-20：固定卡片入口与同页选句

用户确认将制作卡片作为固定功能：顶部导航提供入口，首页与文章文案旁可直接制作卡片，制作过程中选择其他文案不离开编辑器。本轮最初为实现与本地预览；用户同日随后要求多 Agent 复核并上线，后续发布记录见 [Care Studio 发布](../releases/2026-10-20-care-studio.md)。

## 实现

- 主导航加入 Make a card；资源页导航同样提供入口，编辑器标识当前页。
- 现有公开文案的卡片按钮使用 `#message=<公开文案的稳定 ID>`。原文不出现在链接中，片段不产生新的服务端页面或 sitemap 条目；编辑器继续使用原 self-canonical。
- 文案目录从现有文章及首页示例导出，去重后 493 条，35 个分类；未额外生成祝福语。三条超过卡片 320 字符限制的旧文案仍保留原文与复制按钮，不添加卡片按钮。
- 编辑器内按类别浏览文案，每组六条。选择只替换正文，保留插画、标题、收件人和署名；Undo replacement 恢复替换前的正文。清空卡片或浏览器恢复为新访问时清除撤销记录。
- 首页 Finder 的自定义文案按用户点击，完整写入本标签页的一次性 `sessionStorage` 转交项，再进入编辑器。编辑器读取后立即移除，再校验格式和五分钟有效期；后续编辑不存储。URL、统计和网络请求不含自填文字。存储受限时停留原页，提示复制后粘贴。
- 超过 320 字符的转交内容完整保留在输入框，提示缩短并禁止导出，不静默截断。
- 修复实际浏览器发现的点击竞态：输入框失焦触发旧 Finder 重绘，可能移除正被点击的按钮。新按钮的主指针按下阻止该默认失焦行为，键盘点击仍保持正常。

## 保护与成本

原 `content/pages.js`、`script.js`、`styles.css`、卡片 PDF、插画资产均未修改。只在独立脚本/样式中增加交互，旧页静态内容追加有明确标记的入口；首页与隐私页各精确更新一处临时转交说明，避免与新功能矛盾。

`tests/fixtures/production-baseline.json` 仍为 `76d95d9`，未刷新。保护检查逐一验证新增导航、版本化资产、相邻 Copy 原文及目录 ID，再移除严格限定的新增项和恢复两处隐私说明进行旧基线比较；没有放宽到忽略任意 HTML。

仍为静态生成站。复用现有 WebP，Canvas 在浏览器生成 PNG；没有引入 Vercel 图片转换、运行时图片服务或付费接口。
