# Workplace English practice — 第一轮内容与来源记录

日期：2026-09-22。范围：`content/workplace-practice.js` 中的五个英文微练习。

这些练习用于练习情境判断。每题先写明关系、渠道、已知事实和沟通目的，再选本情境下的 best fit。题目、选项、解释和补充示例均为本轮新写；没有转载来源的例句。来源提供真实问题线索或写作原则，不构成对本站答案的背书。

当前状态：AI 起草并进行来源核对；尚未完成真人英语编辑审核或目标学习者测试。没有声称教学效果已获验证，也没有使用医学、劳动法或病假制度结论作为答案依据。涉及工作安排的条件属于题设，不推断任何国家或公司的政策。

## 编辑约束

- 每题保留三项、一个 best fit、两条新写示例；解释较弱选项何时可能适用。
- “正确”表示符合当前题设，不表示有一种放之四海而皆准的英语礼节。
- 示例中的姓名或方括号用于帮助理解，练习不接收用户自由输入。
- 原有例句页保留其查找与复制用途；新练习通过 related 链接回这些页面。
- 来源于 2026-09-22 通过 web 搜索并打开原页核对；参考的是原帖主体、出版方正文或官方 FAQ，没有把搜索摘要里的第三方结论直接当依据。
- noindex、页面模板和 sitemap 由主任务接入；本数据文件与来源记录不更改现有索引配置。
